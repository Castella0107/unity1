## 画面概要
| 項目 | 内容 |
|---|---|
| 画面名 | GamePlay (PVP) |
| 画面ID | SCR-PVP-PLAY |
| 機能概要 | PVP 対戦で1曲をプレイ。自スコアと相手情報（VSバー）を表示し、完走でリプレイをサーバー提出 |
| 対応シーン名 | GamePlay.unity（ソロと共用。`GamePlayParameters.IsPvp=true` で PVP HUD 有効化。関連: `Game/GamePlayController.cs` / `UI/HUD/GameHud.cs` / `Game/PauseMenu.cs` / `Network/PvpProgressOverlay.cs`） |

## 画面レイアウト
- 中央: ①レーン/ノーツ（ソロと共通）
- 上中央: ②VS スコアバー（自分=シアン左 / 相手=レッド右） ③リード差
- 右上: ④相手情報ボックス（名前・レート） ⑤進捗オーバーレイ（OnGUI）
- そのほかソロ共通 HUD（スコア・コンボ・ゲージ等）
- 下部: ⑥操作説明バー

## 操作 / イベント定義
| No | 操作 / イベント | アクション（結果） | 遷移先 |
|---|---|---|---|
| E1 | ノーツ入力 | 判定処理・スコア加算（ソロと共通） | （同一画面） |
| E2 | ESC 長押し（6秒） | リタイア（`AbortMatch("Retired")`）。押下中は残秒数を表示 | PVPMatchEnd |
| E3 | ESC を途中で離す | リタイアキャンセル（カウントリセット） | （同一画面） |
| E4 | 完走 | リプレイ保存 → `OnSongCompleted` → song/submit → 相手提出待ち → 曲リザルト | PVPSongResult |

## 表示制御 / 活性制御
| 対象項目/操作 | 条件 | 制御 |
|---|---|---|
| ポーズメニュー | PVP 中 | **無効**（ポーズ不可。ESC はリタイア長押しのみ） |
| PVP HUD（②③④） | ソロプレイ時 | 非表示（`SetPvpContext` 呼出時のみ有効） |

## 入力チェック / ガード条件
| 対象 | チェック内容 | エラー時の挙動 |
|---|---|---|
| リタイア誤爆 | 6秒長押し必須＋残秒数表示 | 離せばキャンセル |
| 曲提出の二重送信 | 完走時に1回のみ呼ばれる。サーバー側も already 系を拒否 | — |
| リプレイ欠落 | replayPath 空 / ファイルなし | `AbortMatch` → PVPMatchEnd（中断表示） |
| 相手の提出待ちタイムアウト | 1.2秒×150回 = **最大180秒** | `AbortMatch("Opponent song submit timeout")` → PVPMatchEnd「MATCH INCOMPLETE」 |
| progress 送信の多重 | in-flight 1件制限（前回完了まで次を送らない） | — |

## 画面内状態遷移
| 状態 | 遷移元・契機 | 遷移先・契機 | 許可される操作 |
|---|---|---|---|
| プレイ中 | 開始 | 完走 / リタイア成立 | ノーツ入力, ESC長押し |
| リタイア長押し中 | ESC押下 | 6秒成立 or 離す | ESC維持/解放 |
| 提出・相手待ち | 完走 | 両者提出 or 180秒タイムアウト | なし（自動） |

## 画面遷移（入出）
| 方向 | 相手画面 | 契機 |
|---|---|---|
| IN | PVPSongSetup | READY |
| OUT | PVPSongResult | 完走 → 両者提出完了 |
| OUT | PVPMatchEnd | リタイア / 提出失敗 / 相手タイムアウト |

## タイムアウト / 自動遷移
| 契機 | 時間 | 遷移先・動作 |
|---|---|---|
| 相手の同曲提出待ち | 180秒 | 中断（MATCH INCOMPLETE）→ PVPMatchEnd |

## サーバー通信
| タイミング | API | 概要 |
|---|---|---|
| 0.5秒ごと | POST /api/pvp/match/{id}/progress | 自進捗（songIndex / percent / score）送信、応答で両者スナップショット取得 |
| 完走時 | POST /api/pvp/match/{id}/song/submit | リプレイ（Base64）+ 難易度を提出 |
| 相手未提出時 1.2秒ごと | GET /api/pvp/match/{id}/song/{idx}/result?userId= | 両者提出の成立確認（最大180秒） |
| 開始時 1回 | GET /api/pvp/user/{opponentId}/stats | 相手レート表示用 |
