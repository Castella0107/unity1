## 画面概要
| 項目 | 内容 |
|---|---|
| 画面名 | PVPSongSetup |
| 画面ID | SCR-PVP-SETUP |
| 機能概要 | 各曲の本戦前に難易度（倍率付き）とプレイ設定を選び、READY で GamePlay を起動。3曲とも毎回通る |
| 対応シーン名 | PVPSongSetup.unity（`UI/Pvp/PvpSongSetupController.cs`） |

## 画面レイアウト
- 上部: ①ヘッダー "SONG n / 3"
- 左: ②ジャケット ③曲名
- 中央: ④難易度ボタン ×4 ⑤選択難易度+倍率ラベル ⑥相手の難易度
- 右: ⑦ノートスピード（±） ⑧判定オフセット（±） ⑨表示オフセット（±）
- 下部: ⑩ステータス ⑪READY ボタン ⑫CANCEL ボタン ⑬操作説明バー

## 画面項目定義
| No | 項目名 | 種類 | 内容 / 初期値 | 必須 | 備考 |

## 操作 / イベント定義
| No | 操作 / イベント | アクション（結果） | 遷移先 |
|---|---|---|---|
| E1 | ←→ | 存在する難易度のみ循環切替 | （同一画面） |
| E2 | Shift+←→ | ノートスピード ±0.5 | （同一画面） |
| E3 | Ctrl+←→ | 判定オフセット ±1ms | （同一画面） |
| E4 | Alt+←→ | 表示オフセット ±1ms | （同一画面） |
| E5 | Space / Enter / READY / パッド A | 設定を PlayerPrefs 保存 → 選択難易度を試合状態へ反映 → GamePlay 起動 | GamePlay (PVP) |
| E6 | ESC / CANCEL / パッド B | 辞退確認 → 確定で Title | Title |

## 表示制御 / 活性制御
| 対象項目/操作 | 条件 | 制御 |
|---|---|---|
| 難易度ボタン | 譜面ファイルなし | 非活性・暗転（選択中=シアン、その他=白） |
| READY・難易度ボタン | READY 押下後（"Starting..."） | 非活性（多重起動防止） |
| 全入力 | ConfirmDialog 表示中 | 無効 |

## 入力チェック / ガード条件
| 対象 | チェック内容 | エラー時の挙動 |
|---|---|---|
| 選択難易度に譜面なし | `_diffAvailable` | READY 不可、"Selected difficulty unavailable." 表示。初期表示時は存在する最高難度へ自動フォールバック |
| 譜面存在チェック不可環境（Android 等） | 1件も検出できない | 全難易度を許可するフォールバック |
| マッチ未存在 | IsActive false | "(no active match)" → BACK で Title |

## 画面内状態遷移
単一状態（設定中 → READY 後はロック）。

## 画面遷移（入出）
| 方向 | 相手画面 | 契機 |
|---|---|---|
| IN | PVPBanPhase | START MATCH（1曲目） |
| IN | PVPSongResult | NEXT SONG（2・3曲目） |
| OUT | GamePlay (PVP) | READY |
| OUT | Title | ESC → 辞退確定 |

## タイムアウト / 自動遷移

|---|---|---|
| なし（READY 待ちは無期限） | — | — ※「準備完了20秒待ち・未完了側不戦敗」は仕様確定済みだが**未実装**（サーバー同期が必要、K 領域） |

## サーバー通信
なし（譜面存在チェック・PlayerPrefs はローカル）。

## 補足 / 未確定事項
- **両者のプレイ開始同期なし**: 現状は各自が READY した時点で各自の GamePlay が始まる（非同期進行）。完走後の song/submit 同期で帳尻を合わせる方式。開始同期（READY 20秒待ち）はサーバー実装待ち。
- 相手の難易度表示（⑥）はサーバー API 待ちでダミー。
