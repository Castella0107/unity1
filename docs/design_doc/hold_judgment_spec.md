## 1. ホールド1本の構造

1本のホールドは **頭（支点）＋ボディティック（0本以上）＋尾** に分解され、それぞれが独立に判定される。
スコア上のノート数は `N = 2 + tick数`（頭1 + ティック数 + 尾1）。

- **ボディティック**は「1小節8刻み（4/4で八分音符ごと）」。終端の 1/8 手前まで配置され、終端の 1/8 に入るティックは必ず1本だけ。
- **無敵ゾーン = 終端の最後の 1/8 = 「最終ボディティック＋尾」**。この区間だけ離上ルールが特別扱いになる。
- ティック密度・N・小節長式・判定窓は本仕様変更（ホールド終端無敵ゾーン化）でも**不変**。

### 判定窓（頭）

| 判定 | 許容タイミング差 | 備考 |
|---|---|---|
| P+ | ±16 ms | ≈1 フレーム |
| P | ±33 ms | ≈2 フレーム |
| Great | ±66.6667 ms | 4 フレーム = 1000/60×4 |
| Good | ±100 ms | 6 フレーム = 1000/60×6 |
| Miss | ±100 ms 超 | — |

`FrameMs = 1000.0 / 60.0`（丸めリテラル禁止・サーバーも同一式）。
※ WIDE 判定（P+±25 / P±50 / Great±75、Good は同じ ±100）はソロ専用。PVP・パリティ生成は常に標準窓（`WideActive=false`）。

`GUARD_MS = 50 ms`（ホールド中の短い離上を許容する猶予）。

## 2. 頭（支点）

押下タイミング差 `delta = 押下時刻 − 頭時刻` で決まる。

| 操作 | 判定 |
|---|---|
| ±16 ms 以内で押下 | **P+** |
| ±33 ms 以内 | **P** |
| ±66.6667 ms 以内 | **Great** |
| ±100 ms 以内 | **Good** |
| ±100 ms 窓内に一度も押さない（タイムアウト） | **Miss ＋ ホールド放棄** |

- **頭が Miss（放棄）になると、そのホールドの tick・尾は一切判定されない**（未解決のまま。miss にもカウントされず、N にだけ残る）。
  → 判定カウント合計 < N になるのはこの既存仕様（回帰ではない）。
- 頭が Good 以上で通れば、以降の tick・尾へ進む。
- 窓より早すぎ／遅すぎる単発押しは無視され、頭は未確定のまま待つ。

## 3. ボディティック（無敵ゾーンより手前の「実ティック」）

各ティック時刻を再生ヘッドが通過した瞬間に評価する。

| そのティック時点の状態 | 判定 |
|---|---|
| 押下中（通常） | **P+** |
| 押下中で、直前に「50 ms 超の離上→再押下」で復帰した最初の1本 | **Great**（1回だけ。以降 P+） |
| 離上中だが、離した瞬間から 50 ms 以内に来たティック | **P+**（短い離しは許容） |
| 離上中で、離してから 50 ms を超えて来たティック | **Miss**（コンボ断。ただし放棄はしない） |

- Miss になってもホールドは放棄されず、**再押下すれば次のティックから復帰**する（復帰直後の1本が Great、その後 P+）。
- 手前ティックは **P+ / Great / Miss しか出ない**（P・Good は出ない）。
- 50 ms ちょうどは許容側（P+）、50.001 ms から Miss。

---

## 4. 無敵ゾーン（最終ボディティック＋尾）

「離上に対する新たなペナルティを課さない」のが唯一の違い。
**押下ブランチは §3 と完全に共通**、**離上ブランチだけ**が変わる。

| 終端での状態 | 最終ティック / 尾の判定 |
|---|---|
| 押下中（再押下含む） | 復帰中なら **Great**（1回）、以降 **P+**。**手前が Miss でも終端で押していれば復帰する** |
| 離上中 → 直前の実ティック判定を複製 | 以下に細分 |
| └ 直前の実ティックが P+（押せていた） | **P+**（＝終端で離しても救済） |
| └ 直前の実ティックが Miss（手前でコンボ断） | **Miss**（救済せず温存・加点なし） |
| └ 複製元の実ティックが無い（ボディティック1本だけ＝それ自身が無敵） | **頭の判定にフォールバック**（頭が P なら P） |

- この「頭フォールバック」が、**ティック／尾に P が出る唯一の経路**（通常の押下ティックは P+ どまりで P にはならないため）。

---

## 5. 短ホールド特例（長さ ≤ 1/8、ボディティック0本）

- 頭が **Miss** → 放棄（頭のオートミスで Miss 1件、尾は未解決）。
- 頭が **Miss 以外**（P+/P/Great/Good で通った） → **尾は無条件 P+**。
  踏襲ではなく **フラット P+**（頭が P/Great/Good でも尾は P+、離していても P+）。

---

## 6. コンボ・スコアへの効き方

- **コンボ**: P+/P/Great/Good で継続、**Miss で 0 に断**。
- **スコア（マイクロ点）**: P+ と P は**同点（満点）**、Great = 199/200、Good = 3/4、Miss = 0。
- **P+ と P の差はセクタータイブレークのみ**（P+ = +2 / P = +1）。表示スコアは同じでも、単一ティックホールドで尾が「頭の P」にフォールバックしたケースなどは、P+ プレイとタイブレーク値が変わり**レートに効く**。
  → パリティ照合では `perfect_plus_count` と `perfect_count` を**別々に**確認すること。
- 満点整合: 全 P+ プレイでは無敵ゾーンも P+ を踏襲するので 1,000,000 は不変。

## 7. 代表的な操作シナリオ（効きが分かるもの）

| シナリオ | 結果 |
|---|---|
| 頭から尾まで押しっぱなし | 頭〜全ティック〜尾すべて **P+**（満点整合） |
| 終端で離しただけ（手前は押せていた） | 最終ティック＋尾が直前 P+ を複製し **救済**（全 P+）。旧仕様なら尾 Miss |
| ゾーン手前でコンボが切れたまま終端も離す | 最終ティック＋尾は **Miss を複製**（救済されない） |
| 手前で Miss → ゾーン手前で押し直す | 復帰ティック=**Great**、尾=**P+** |
| 50 ms 超離して押し直す | 離している間のティックが Miss、再押下後の最初の1本だけ Great、以降 P+ |
| 50 ms 以内で離して押し直す | Miss にならず（許容 P+）、復帰 Great も出ない |
| 単一ティックホールドで終端離上 | 複製元が無く**頭の判定にフォールバック**（頭 P → 尾 P） |
| 短ホールド（tick0本）で頭 P、終端離上 | 尾は**フラット P+** |

参考: 上記ルールの実出力例 = golden vector（`docs/handoff/2026-07-01_hold_tail_invincible/vectors/`）。
real_castella song1 は終端 Miss 複製で pp 減、song3 は終端救済で miss 解消。
