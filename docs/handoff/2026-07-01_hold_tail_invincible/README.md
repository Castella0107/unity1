## 仕様（確定）

用語:
- **支点（ヘッド）** = ホールドの頭。押下タイミングで P+/P/Great/Good/Miss が確定する。
- **無敵ゾーン** = ホールド終端の最後の 1/8（= ホールドティック 1 間隔）。
  ティック間隔は 1/8 なので、この区間に入る **ボディティックは必ず最後の 1 本だけ**。
  無敵ゾーンの構成要素 = 「最終ボディティック」＋「尾（tail, EndMs）」。

### 1. 通常のホールド（長さ > 1/8 ＝ ボディティックが 1 本以上ある）

- **無敵ゾーン（最終ボディティック＋尾）は「離上に対する新たなペナルティ」を課さない。**
  従来「終端で離すと尾が Miss」だったのを撤廃。判定は**その時点の押下状態**で決まる:
  - **押下中（再押下含む）** → 通常どおり**復帰判定に従う**（復帰直後の最初の判定だけ Great、以降 P+）。
    **直前が Miss（手前でコンボ断）でも、終端で押していれば復帰する**（Great→P+）。
    ＝無敵ゾーンでも押下中は「手前ティックと同じ通常ロジック」。
  - **離上中** → 新たなペナルティを課さず、**直前の実ティック判定をそのまま複製**する:
    - 直前が **P+**（押せていた）→ **P+**（＝終端で離しても救済）
    - 直前が **Miss**（ゾーン手前で既にコンボ断）→ **Miss** を複製（コンボ断のまま・加点なし）
  - 複製元の実ティックが 1 本も無い場合（ボディティックが 1 本＝それ自身が無敵の場合）は **ヘッド判定にフォールバック**。
- 無敵ゾーン **より手前**のボディティック（＝実ティック）は従来どおり:
  - 押下中 = P+（ガード超過離上からの復帰直後の最初の 1 tick のみ Great）
  - ガード（50ms）内の短い離上 = 許容（P+）
  - ガード超過の離上中の tick = Miss（コンボ断。放棄はせず再押下で復帰可）
- ※ 実装上、無敵ゾーンと手前ティックの違いは **離上ブランチだけ**（手前=guard/Miss、ゾーン=直前を複製）。
  押下ブランチ（復帰→Great→P+）は完全に共通。
- ※ ボディティックは押下中なら常に P+（P にはならない）ので、通常ホールドで尾が P になることは無い
  （複製元が実ティックのため）。P はヘッドフォールバック時（単一ティックホールド）でのみ出る。

### 2. 1/8 以下の短いホールド（ボディティックが 1 本も無い）

- 支点（ヘッド）が **MISS** → ホールドは放棄（従来どおり、頭のオートミスで MISS 1 件計上、尾は解決しない）。
- 支点が **MISS 以外**（P+/P/Great/Good で通った） → 尾は **無条件 P+**（離上していても可）。
  ※短ホールドは「踏襲」ではなく **フラット P+**（ヘッドが P でも尾は P+）。

## 3. スコアへの効き方（重要）

- P+ と P は **表示スコアは同点**（どちらも満点マイクロポイント）。
  ただし **セクタータイブレーク値が異なる**（P+ = +2 / P = +1）。同点タイブレークはレートに効くため
  **P+/P の踏襲を正確に**再現すること。
- Great = 199/200、Good = 3/4、Miss = 0（不変）。
- コンボ境界は Good（P+/P/Great/Good で継続、Miss で 0）。
- 満点（1,000,000）整合は維持: 全 P+ プレイでは無敵ゾーンも P+ を踏襲するので満点は変わらない。
